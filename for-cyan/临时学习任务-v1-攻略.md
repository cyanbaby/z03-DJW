# GitHub 远程仓库任务

## 1. 在 GitHub 创建仓库

仓库名：

```
todo-list
```

要求：

- 仓库公开（Public）
- 不要勾选 README 初始化

---

## 2. 本地提交代码

要求完成：

```
git add .git commit -m "init project"
```

理解：

- 工作区
- 暂存区
- 提交记录

---

## 3. 关联远程仓库并推送

完成：

```
git remote add origin 你的仓库地址git push -u origin master
```

如果是新版 Git：

```
git push -u origin main
```
