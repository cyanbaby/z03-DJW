# 一、先记住一句核心话

JavaScript 本质：

- 万物皆对象（除了部分 primitive）
    
- 对象通过「原型链」实现继承
    
- 函数是特殊对象
    
- 构造函数只是“可以 new 的函数”
    

所以：

```
对象 ← 原型链 ← 对象 ← 原型链 ← Object.prototype ← null
```

整个 JS 世界都建立在这条链上。

---

# 二、最核心的关系（必须背下来）

```
实例对象.__proto__ === 构造函数.prototype
```

例如：

```
function Person() {}

const p = new Person()

p.__proto__ === Person.prototype // true
```

这是整个原型链世界最核心的一句话。

---

# 三、prototype 和 **proto** 到底谁是谁？

很多人最混乱的地方在这里。

---

## 1. prototype

```
只有函数才有 prototype
```

它是：

```
“未来实例对象共享的公共区域”
```

例如：

```
function Person() {}

Person.prototype.sayHi = function () {
  console.log('hi')
}
```

这里：

```
Person.prototype
```

就是未来所有 Person 实例共享的方法区。

---

## 2. **proto**

```
所有对象都有 __proto__
```

它是：

```
“当前对象的原型指针”
```

用于：

```
向上查找属性
```

例如：

```
p.__proto__ === Person.prototype
```

意思：

```
p 找不到属性时
会去 Person.prototype 上找
```

# 六、属性查找过程（原型链）

例如：

```
p1.sayHi()
```

发生了什么？

---

## 第一步

先找：

```
p1 自己有没有 sayHi
```

没有。

---

## 第二步

顺着：

```
p1.__proto__
```

找到：

```
Person.prototype
```

发现：

```
sayHi
```

于是执行。

---

## 第三步

如果还没有：

继续向上：

```
Person.prototype.__proto__
```

其实就是：

```
Person.prototype.__proto__ === Object.prototype
```

---

## 第四步

再没有：

继续向上：

```
Object.prototype.__proto__
```

结果：

```
null
```

查找结束。

# 八、new 到底做了什么？（超级重点）

```
const p1 = new Person('zs')
```

实际上 JS 内部大概做了：

```
function myNew(fn, ...args) {
  // 1. 创建空对象
  const obj = {}

  // 2. 建立原型链
  obj.__proto__ = fn.prototype

  // 3. this 指向新对象
  const result = fn.apply(obj, args)

  // 4. 返回对象
  return result instanceof Object ? result : obj
}
```

# 十、构造函数到底是什么？

构造函数本质：

```
就是普通函数
```

区别只是：

```
被 new 调用了
```

例如：

```
function Person() {}
```

它本来只是普通函数。

只有：

```
new Person()
```

时，才成为“构造函数”。

---

# 十一、constructor 是什么？

每个 prototype 默认都有：

```
prototype.constructor
```

例如：

```
Person.prototype.constructor === Person
```

作用：

```
记录“这个原型对象属于谁”
```

关系图：

```
Person
   │
   │ prototype
   ▼
Person.prototype
   │
   │ constructor
   └──────────────────→ Person
```

# 十二、ES5 继承（最经典）

## 1. 父类

```
function Animal(name) {
  this.name = name
}

Animal.prototype.say = function () {
  console.log(this.name)
}
```

---

## 2. 子类

```
function Dog(name, age) {
  Animal.call(this, name)
  this.age = age
}
```

这里：

```
Animal.call(this)
```

作用：

```
继承实例属性
```

---

## 3. 继承原型方法

```
Dog.prototype = Object.create(Animal.prototype)
```

作用：

```
建立原型链
```

等于：

```
Dog.prototype.__proto__ = Animal.prototype
```

---

## 4. 修复 constructor

```
Dog.prototype.constructor = Dog
```

# 十四、ES6 class 本质

很多人以为：

```
class 是新东西
```

其实不是。

---

## class 本质还是原型链

```
class Person {
  constructor(name) {
    this.name = name
  }

  sayHi() {
    console.log(this.name)
  }
}
```

实际上底层类似：

```
function Person(name) {
  this.name = name
}

Person.prototype.sayHi = function () {
  console.log(this.name)
}
```

---

# 十五、class 继承本质

```
class Dog extends Animal {}
```

本质：

```
Dog.prototype.__proto__ = Animal.prototype
```

还是原型链。

# 十八、最变态但最重要的一组关系

```

因为：

```

函数也是对象
```

JS 在设计底层时：

```
Function 和 Object 互相引用

形成闭环。
