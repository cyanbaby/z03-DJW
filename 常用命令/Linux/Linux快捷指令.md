| 命令      | 拼读               | 英文意思                    | 中文作用           |
| ------- | ---------------- | ----------------------- | -------------- |
| `pwd`   | 皮-W-D / P-W-D    | print working directory | 查看你现在在哪个文件夹    |
| `ls`    | L-S / 艾勒-艾斯      | list                    | 查看当前文件夹里有什么    |
| `cd`    | C-D / 西-迪        | change directory        | 进入某个文件夹 / 切换目录 |
| `mkdir` | make-dir / 迈克-德尔 | make directory          | 新建文件夹          |
| `touch` | 塔吃               | touch                   | 新建文件           |
| `rm`    | R-M / 阿尔-艾姆      | remove                  | 删除文件/文件夹       |
| `cat`   | 凯特               | concatenate / cat       | 查看文件内容         |
| `mv`    | M-V / 艾姆-威       | move                    | 移动文件 / 重命名     |
| `cp`    | C-P / 西-皮        | copy                    | 复制文件/文件夹       |
| `vim`   | 维姆               | Vim editor              | 用 Vim 编辑文件     |
