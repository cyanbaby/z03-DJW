| 命令               | 拼读         | 英文意思       | 中文作用          |
| ---------------- | ---------- | ---------- | ------------- |
| `git init`       | git 伊尼特    | initialize | 初始化本地仓库       |
| `git status`     | git 斯得忒斯   | status     | 查看当前代码状态      |
| `git add`        | git 艾德     | add        | 把文件加入暂存区      |
| `git commit`     | git 克米特    | commit     | 提交一次版本记录      |
| `git log`        | git 老格     | log        | 查看提交历史        |
| `git remote add` | git 瑞某特 艾德 | remote add | 关联远程仓库        |
| `git push`       | git 普许     | push       | 把代码推送到 GitHub |
| `git pull`       | git 普尔     | pull       | 从远程拉取最新代码     |
| `git clone`      | git 克隆     | clone      | 克隆远程仓库到本地     |
| `git branch`     | git 布兰吃    | branch     | 查看/创建分支       |
| `git checkout`   | git 切克奥特   | checkout   | 切换分支          |
| `git merge`      | git 莫纸     | merge      | 合并分支          |
