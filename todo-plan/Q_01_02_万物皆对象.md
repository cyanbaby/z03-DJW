---

# 一、什么叫“万物皆对象”？

先别被这句话吓到。

它的大白话意思其实是：

```
JavaScript 里面大部分东西本质上都是“一个可以存东西的盒子”
```

这个“盒子”：

- 可以放属性
- 可以放方法
- 可以动态扩展
- 可以通过 . 访问

这个盒子就叫：

```
对象（object）
```

---

# 二、对象到底是什么？（最重要）

对象你可以理解成：

```
一个装数据的字典 / 容器 / 盒子
```

例如：

```
const user = {  name: '张三',  age: 18,  sayHi() {    console.log('hi')  }}
```

这里：

```
user 就是对象
```

因为它里面可以装：

- name
- age
- sayHi

---

# 三、“万物”到底有哪些？

JS 里很多东西本质都是对象。

例如：

---

## 1. 普通对象

```
const obj = {}
```

这是对象。

---

## 2. 数组

```
const arr = [1, 2, 3]
```

数组其实也是对象。

你甚至可以：

```
arr.name = '数组'
```

因为数组本质是特殊对象。

---

## 3. 函数

```
function test() {}
```

函数也是对象。

你甚至能：

```
test.age = 18
```

这很离谱，但真的可以。

因为：

```
函数 = 可执行的对象
```

---

## 4. 日期对象

```
new Date()
```

也是对象。

---

## 5. 正则

```
/abc/
```

也是对象。

---

## 6. Map

```
new Map()
```

也是对象。

---

## 7. Promise

```
new Promise(() => {})
```

也是对象。

---

# 四、为什么说它们是对象？

因为它们都有：

```
属性方法原型链__proto__
```

例如：

```
const arr = [1,2,3]arr.lengtharr.push()arr.__proto__
```

都有。

所以：

```
数组本质是对象
```

---

# 五、那 primitive 是什么？

primitive：

```
原始类型 / 基础类型
```

它们不是对象。

---

# 六、primitive 有哪些？

JS 一共主要这些 primitive：

```
stringnumberbooleanundefinednullsymbolbigint
```

# 八、primitive 和对象最核心区别

# 对象

可以：

```
const obj = {}obj.name = 'zs'
```

能加属性。

---

# primitive 不行

```
const str = 'abc'str.age = 18console.log(str.age)
```

结果：

```
undefined
```

因为 primitive 不是对象。

它不能真正存属性。

---

# 九、但为什么字符串能调用方法？

这是最容易懵逼的地方。

例如：

```
'abc'.toUpperCase()
```

你会想：

```
不是说字符串不是对象吗？为什么还能调用方法？
```

---

# 十、真相：JS 偷偷帮你“装箱”了

JS 内部偷偷干了：

```
new String('abc')
```

临时把 primitive 包装成对象。

过程类似：

```
const temp = new String('abc')temp.toUpperCase()
```

调用完立刻销毁。

所以你才感觉：

```
字符串像对象
```

但其实：

```
它本身不是对象
```

---

# 十一、装箱图（非常重要）

```
primitive string'abc'   │   │ 临时包装   ▼new String('abc')   │   ▼String.prototype.toUpperCase()   │   ▼执行结束立刻销毁
```

# 十二、typeof 最经典判断

---

## primitive

```
typeof 123
```

结果：

```
'number'
```

---

## 对象

```
typeof {}
```

结果：

```
'object'
```

---

## 数组（经典坑）

```
typeof []
```

结果：

```
'object'
```

因为：

```
数组本质也是对象
```

---

## 函数

```
typeof function(){}
```

结果：

```
'function'
```

因为：

```
函数是特殊对象
```
